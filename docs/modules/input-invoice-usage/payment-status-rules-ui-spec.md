# 支付状态规则设置（2026-09-28）

本页使用 HeroUI 原生字段和现有 AppDrawer。后端、保存与迁移合同见 [boundary-io](boundary-io.md#2026-09-28-发票张数反提候选与可编辑规则)。

- 展示启用、优先级、输出分类、显示名称、真实 OA 申请人选择及 OA/流水/金额匹配条件。
- 支持新增规则、编辑条件和删除草稿中的规则，统一点击保存后生效；未保存关闭需保留退出保护。按优先级首条命中，禁止重复优先级、非法类型和明确矛盾条件。
- 申请人不锁定固定姓名，也不限制为反提凭据名单。相同输出分类统一文案。
- 移除“待处理发票处理方向”和手写原因区域；条件解释由后端生成。空规则列表是合法状态，读取不恢复默认规则。
- 保存携带既有版本与幂等键，版本冲突和保存失败明确反馈。新配置需要与列表/筛选/导出回读一致。
- 不新增卡片嵌套、通用规则编辑器、表达式脚本或全局样式覆盖。

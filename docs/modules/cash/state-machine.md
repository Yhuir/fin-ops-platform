# 状态与事务

唯一详细定义见[技术设计](../../dev/cash-module-technical-design.md)的事务、删除、任务与查询章节。

- 收付流水存在/物理删除；已删创建 ID 不允许延迟提交复活。
- 事项未结/部分/结清、票据可用/使用/冲抵由金额事实派生，不重复保存一份人工状态。
- 月任务有目标与实际累计：未办/部分/完成；核对任务 pending/checked；未还不产生流水。模板更改保存必要旧月事实后影响未来，不在 GET 补写。
- 配置和持久对象采用版本冲突；复合修改成功整体提交，失败整体回滚。无跨池补偿或后台报表重建。

前端已有loading/empty/error/conflict、抽屉确认与写后重读；上线证据见实施计划§12，不覆盖新的统一UI目标。

已实现交互状态：顶部draft与applied分离；浮层打开从applied建立selectionDraft→勾选/候选搜索不查询主表→应用前校验完整下一query→合法时更新本列并回第1页→主查询加载/成功或明确失败。超量或编码超限保留当前有效条件/结果与浮层草稿，明确报错，不发送无效请求。Escape/外部关闭取消浮层草稿；重置清除本视图草稿并恢复默认；排序直接应用。切视图保留已应用条件快照，退现金页/撤权卸载所有条件、rows和Portal。成功写入与后续读取失败分别反馈，不重复写。完整规则见技术设计§13.2、UI§3.6，实际验证见实施§14。

# 归档区

归档区保存历史资料，用于追溯，不作为当前需求、架构或开发入口。

## 目录

- `prompts/`：历史 Codex prompt。
- `superpowers/plans/`：历史实施计划。
- `superpowers/specs/`：历史设计文档。
- `legacy-docs/`：整理前的旧 PRD、roadmap、solution design、task breakdown。
- `legacy-dev/`：整理前的阶段性开发说明。
- `product-sources/`：原始业务需求源文档。

## 使用规则

- 新需求不要写入归档区。
- 如果归档内容仍有效，应提炼到 `docs/product-specs/`、`docs/architecture/`、`docs/dev/` 或 `docs/operations/`。
- Prompt 仅用于追溯当时的执行意图，不作为当前验收标准。

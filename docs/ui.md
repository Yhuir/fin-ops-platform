# 界面与交互约定

React 19、TypeScript、HeroUI v3 与 Tailwind CSS v4 构成 UI。主要用户是长时间处理对账、核销、异常与导出的内部财务人员，界面优先保证扫读效率和可追溯性。风格是紧凑、清晰的财务工作台：浅色背景、白色表面、低饱和边框，蓝色主操作，绿色成功、橙色提醒、红色失败。颜色和尺寸以 [styles.css](../web/src/app/styles.css) 等实际样式为准，文档不复制整套 token。

## 公共边界

页面持有 API 和业务状态；公共表格、抽屉、按钮、分段组件只接收 props 并回传事件。普通页复用 FinanceTable，关联台分组布局由关联台拥有；现金可以复用纯 UI，但不接入普通页面持久 session。

表格保留清晰的列对齐、金额精度、日期单位、可读空值和真实业务统计。服务端分页/排序由服务端拥有，页面不能对当前页冒充全量排序或总数。宽表通过横向滚动保持可达；需要文本复制的调用方显式启用选择能力。小屏侧栏和抽屉不遮挡主要操作。

## 分段、计数与状态

`SegmentedControl`/`SegmentGroup` 复用 HeroUI 受控选择；`Tabs` 用于有内容 panel 的切换。选项 key、业务计数和选择值来自页面，公共组件不请求 API、不计算数量、不接管草稿或页面挂载。重复选择不触发新操作，键盘和焦点语义保持原生可达。

选中态采用清晰底色与文字对比，同工具栏控件保持等高。计数绑定 API 总数而非已加载行数；初次未知不能显示为确定的 0。刷新期间保留最后已知展示计数和稳定宽度，成功响应更新它；查询错误仍明确可见。该展示保留不用于计算、导出或业务判断。

有从属关系的切换采用上层贴边、下层内嵌的结构；共同控制同一张表时，工具栏、表格和分页共享外框。设置、抽屉、现金详情与编辑器连接各自的内容区域；并列条件不伪装成父子关系。分面计数仍按模块查询合同计算，视觉层级不改变统计口径。

未选中项之间有细分隔，选中背景直接绘制在控件上，不使用横跨选项的移动底块。名称和数量紧密居中，计数组以完整标签预留六位数字宽度，更长数值自然扩展并保持可达。公共样式只命中本层列表的直接选项，不能穿透影响嵌套控件。外框不创建新的滚动或裁切边界；宽表仍由表格自身滚动。

loading、empty、error 相互区分。请求乱序不能覆盖当前筛选，失败不能用空列表伪装。异步任务展示自己的真实状态，成功写入后重新 GET；不能增加跨页面等待或自动循环刷新。

## 详情、编辑与导出

详情采用统一抽屉，关闭、返回、确认、错误提示与键盘焦点行为一致。表单保持用户草稿，提交中阻止重复点击；后端拒绝时保留可修正信息，不替用户猜值。业务权限在页面与 API 一致执行。

金额使用各模块规定的币种、精度、正负和统计单位。0、未知、缺失和不适用不能互相替代。不同币种不能直接相加；账户余额不完整时不能给出伪完整合计。

导出由模块定义数据范围、过滤、字段、数量上限和权限；不能把浏览器已加载片段当全量文件。下载成功、失败、等待与取消需可观察。附件复用既有下载/预览边界，不把内部存储 key 或凭据当公共地址。

动画尊重 reduced-motion，避免以过渡掩盖等待。共享组件调整回归普通页、关联台、现金和窄屏场景，优先复用现有交互测试。

## OA、流水与发票来源详情

各页面的原始单据详情使用 `EntityDetailContent`，数据由 `source_record_details.py` 统一投影。页面继续负责自己的鉴权 API 与精确身份查询，公共组件不读数据库、不请求列表、不推断业务字段。服务端输出 `sections`，关联台详情为 `source_sections`；`document_id/document_kind/document_title` 只用于同一单据分组与导航，不作为字段展示。内部 ID、关联状态、归集合计不混入来源字段；缺失来源详情明确失败，不能用列表摘要补齐。

单据按来源分组，原始状态、零值和原始精度保留，缺失字段不补造；发票商品行与 OA 费用行完整保留。多张单据在一个抽屉内以完整标识导航、独立展开并支持展开全部；发票商品行按真实票身份归到一张票，拆分流水指向原始父交易且只显示一次。红蓝票读取全部对应原票详情。

抽屉最大宽度 800px，正文 14px、横向内边距 24px，窄屏缩至 16px。字段值包括金额、余额和税额全部左对齐，长票号与文字自然换行，不省略。内容只有一个纵向滚动区域，关闭按钮固定可达，不显示说明性副标题或来源技术说明。

详情按打开行为读取；切换或关闭取消前一个请求，迟到响应不覆盖当前单据。流水拆分作为独立操作区按需加载，保留服务端权限、失败反馈和未保存草稿关闭保护；收起单据或操作区不会丢失草稿。

# 业务页面流程总览

本目录面向业务读者梳理财务运营平台的页面业务逻辑。它说明每个页面做什么、用户在页面上怎么操作、操作后影响哪些业务数据和其他页面。

这里不记录开发实现细节。开发维护仍以 `../modules/`、`../app-architecture/`、`../dev/` 和 `../operations/` 为准。

## 全局业务数据流

```text
设置
  -> 银行账户、项目、权限、标签、规则

银行流水导入
  -> 银行明细
  -> 关联台候选
  -> 待找发票、免 OA、外部往来款、成本统计

发票导入
  -> 待找发票、进项发票使用、销项收款、税金抵扣
  -> 关联台候选
  -> 成本统计

OA 数据
  -> 关联台
  -> OA 待付款核对
  -> 进项发票反提 OA、ETC OA 草稿相关流程

ETC 票据管理和 ETC 发票导入
  -> ETC 业务批次
  -> 税金抵扣、成本统计
  -> 提交后以汇总发票形式等待关联台闭环

关联台、批量账务、免 OA、外部往来款
  -> 写入确认或撤回关系
  -> 影响银行明细、发票生命周期、成本统计、税金抵扣、搜索和后续核对页面
```

## 页面间影响关系

| 写入动作 | 影响页面 | 业务原因 |
| --- | --- | --- |
| 银行流水导入确认 | 银行明细、关联台、待找发票、免 OA、外部往来款、成本统计 | 新流水进入系统后，需要重新识别标签、自动匹配 decision、成本归因和无 OA/往来款处理范围。 |
| 发票导入确认 | 待找发票、进项发票使用、销项收款、税金抵扣、关联台、成本统计 | 新发票会改变发票是否已获取、是否已付款、是否可抵扣、是否可与 OA/流水关联。 |
| ETC 发票导入确认 | ETC 票据管理、税金抵扣、成本统计、关联台 | ETC 发票进入业务批次，提交后等待 OA 和银行流水共同闭环。 |
| 关联台确认关系 | 银行明细、待找发票、进项发票使用、OA 待付款、销项收款、税金抵扣、成本统计、批量账务 | 跨对象关系成为核销事实，后续页面需要展示已付款、已收款、已配对或已归因状态。 |
| 关联台撤回关系 | 关联台及所有依赖关系状态的页面 | 撤回后相关对象回到待处理或异常状态，需要重新进入候选、补票、付款或统计流程。 |
| 待找发票规则保存 | 待找发票、发票使用、OA 待付款、销项收款、税金抵扣、成本统计、关联台 | 规则改变会改变哪些流水需要发票、哪些流水可视为无需发票。 |
| 银行标签或自动标签保存 | 银行明细、关联台、免 OA、外部往来款、成本统计 | 标签决定流水业务类型、自动匹配输入和是否进入特定处理页面。 |
| 免 OA 批次提交或撤回 | 免 OA、关联台、银行明细、成本统计 | 无 OA 流水被批量确认后，不能再重复进入普通未配对流程；撤回后重新释放。 |
| 批量账务提交或撤回 | 批量账务、关联台、银行明细、成本统计、发票相关页面 | 批量账务关系也是关联事实，会影响后续核销和统计。 |
| 外部往来款闭环或撤回 | 外部往来款、关联台、银行明细、成本统计 | 往来款闭环会写入可审计关系，关联台已配对区和成本统计需要同步变化。 |
| ETC 批次创建 OA 草稿、确认提交、删除 | ETC 票据管理、关联台、税金抵扣、成本统计 | ETC 批次状态决定本地发票占用、汇总发票行和后续配对入口。 |
| 设置保存或数据重置 | 所有相关业务页面 | 配置会改变标签、项目、权限、OA 范围和数据可见性；重置会使旧展示失效。 |

## 阅读建议

业务梳理先读本页，再按页面阅读具体文档。需要判断页面维护边界、接口契约、测试或运维时，回到 `../modules/README.md`、`../app-architecture/pages.md` 和相关长期事实源。

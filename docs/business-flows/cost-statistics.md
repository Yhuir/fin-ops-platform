# 成本统计

项目成本提供按项目、按流水标签、按银行账户三个视角，统一消费真实来源已确认且属于项目成本范围的成本行。银行流水另有按标签、按时间两个视角，保留完整真实收支。

完成审批的 OA 通过正式关联与银行支出建立成本来源。唯一来源可自动确认，多对多需要保存完整来源分配；待分配状态本身不能直接判定金额是否计入。审批完成时间可空，成本月份取来源付款日期。

右上角“项目成本范围”管理全部银行标签代码的选择：勾选才允许支出进入三个项目成本视角，仍须满足原有 OA/来源或无 OA 项目映射条件。默认排除内部往来和未标记；普通收入展示禁用复选框。付错退款先冲减原支出，不由收入标签选择控制。

修改复选框是草稿，保存成功后刷新三个成本视角、下钻、导出与待分配计数。全取消为零成本；选择不会改银行流水、配对或已保存的分配，恢复选择后按当前事实计入。全部来源范围外的组不占待分配数量；混合组保留完整对账资料，范围外来源显示短状态。

未知来源金额只在待分配，不进入正式合计。已确认来源但日期缺失的成本保留全部期间并单列未定日期金额。期间和搜索共同约束三个视角与导出。

实现与接口见 [模块边界](../modules/cost-statistics/boundary-io.md)，验证见 [测试矩阵](../modules/cost-statistics/tests.md)。银行明细负责真实流水和分类，关联台负责配对，设置模块负责范围配置的事务和版本。

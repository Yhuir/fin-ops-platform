# ETC 发票导入

## 页面目的

ETC 发票导入用于把已确认 ETC 对账任务对应的 zip 发票导入系统。它只处理已经在 ETC 票据管理中完成确认、且当前允许导入的对账任务。

## 主要数据

- 可导入的 ETC 对账任务。
- 待上传的 ETC zip 文件。
- zip 预览结果、任务缺失项、重复跳过、附件补齐、新增和异常数量。
- 确认后的 ETC 发票导入任务状态。

## 页面流程

- 进入页面后，先选择已确认且可导入的 ETC 对账任务。
- 点击或拖拽上传 `.zip` 文件；非 zip 文件会被拒绝。
- 点击“开始预览”，页面按所选任务过滤 zip 内发票，并展示本次新增、重复跳过、附件补齐和异常。
- 如果任务还有缺失项或阻塞项，页面提示先回到 ETC 票据管理处理，再重新预览。
- 点击“确认导入”后，系统创建导入任务；页面提示已开始后台导入或已导入 ETC 票据管理。
- 点击“清空”清除当前 zip 和预览；点击“移除”删除单个 zip；点击“返回关联台”回到关联台。

## 状态和异常

- 没有可导入任务时，页面提示先在 ETC 票据管理完成对账确认。
- 任务已更新、预览过期、zip 不匹配、缺少必需发票或确认失败时，页面要求重新预览或返回 ETC 页面处理。
- 确认导入后，不代表关联台、税金或成本页面已立即更新。

## 输出和影响

确认后，ETC 发票进入 ETC 业务批次，并同步影响 ETC 票据管理、税金抵扣、成本统计和关联台。批次后续提交 OA 草稿或删除时，会继续改变这些页面的状态。

## 相关页面

- ETC 票据管理：提供可导入任务，并承接导入后的业务批次处理。
- 关联台：等待 ETC 汇总发票与 OA、银行流水闭环。
- 税金抵扣、成本统计：消费 ETC 发票和批次状态。

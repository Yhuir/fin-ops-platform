# 备份与恢复

## 当前需要备份的对象

- App Mongo 数据库。
- App Mongo GridFS 文件。
- 部署环境变量和配置文件。
- 前端构建产物或镜像。
- 后端代码版本或镜像。
- OA 侧新增菜单和角色 SQL 变更记录。

## 恢复原则

- 先恢复数据，再恢复应用版本。
- 如果 read model 损坏，优先通过重建恢复，不直接手改缓存。
- 如果导入文件丢失，需要先确认 GridFS 或对象存储备份是否完整。
- 如果 OA 权限异常，按 `deploy/oa/README.md` 的账户同步顺序重新检查。

## 后续生产建议

- 建立每日备份。
- 定期演练恢复。
- 对关键集合启用恢复点策略。
- 把导入文件和附件迁到可独立备份的对象存储。

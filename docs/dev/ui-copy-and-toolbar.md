# 界面说明与年月工具栏

日期：2026-09-28。

## 展示边界

页面介绍、重复操作指导及内部实现说明不占用常驻界面。真实金额、用户备注、错误、权限、加载/刷新、操作影响及导出范围继续显示。支付状态规则抽屉按用户要求完整删除优先级解释段落，规则编辑与执行语义不变。

公共组件继续采用 HeroUI：BusinessPeriodPicker 的范围组合外框为 46px（内部36px、上下4px内边距、1px边框），和 SegmentedControl 一致。OA、销项、成本工具栏搜索/查询以及银行自动标签规则按钮同步等高。非分段表单年月控件保留40px，不改变导出弹窗密度。窄屏允许换行；输入 selection/years、输出 onChange 及各页面查询状态不变。不增加 JS 布局测量、网络请求、依赖、API、数据库、read model 或 worker。

## 旧代码清理

删除说明专属 JSX 与三个无引用 CSS 块（批量账务副标题、销项筛选副标题、空导入统计）。销项说明容器改成仅刷新时渲染的状态容器。删除已被共有尺寸取代的 OA/销项日期局部覆盖。ETC 未选择批次不渲染重复说明，已选批次无流程仍明确显示。公共 AppDialog/PageScaffold 的 description 能力有其他消费者，继续保留。

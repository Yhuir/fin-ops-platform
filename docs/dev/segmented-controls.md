# 全 App 原生分段切换

日期：2026-09-28。仅改变前端展示和键盘语义，不修改业务分类、统计单位、API、权限、持久化、worker 或数据库。

## 边界与 I/O

- `web/src/components/common/SegmentedControl.tsx` 提供受控的 HeroUI `ToggleButtonGroup` / `ToggleButton` 展示封装；`SegmentGroup` / `Segment` 供现有集合选择回调、空选择和分组标题使用，`SegmentedControl` 供简单选项列表使用。
- 输入为选项稳定 key、标签（业务 owner 提供计数）、当前选择、禁用状态、无障碍名称和选择回调；输出只有用户选择。重复选中不产生新回调。公共组件不请求 API、不写存储、不计算数量、不接管草稿或页面挂载。
- 已有内容 Tabs 保留 HeroUI `Tabs` 的状态和 panel 语义，统一使用 `app-segments` 样式及原生 `Tabs.Indicator`。原生指示器也用于 ToggleButtonGroup 的选择上下文，不添加动画依赖或自行计算选中块位置。
- `segmentedControl.css` 只作用于显式采用 `app-segments` 的控件；连续浅底框、品牌实蓝选中块与白字、键盘焦点、减少动画偏好、内部横向滚动。短组可以 fullWidth；不强制所有工具栏占满整行。
- 日期外层保留 HeroUI Button + Popover 的复合语义；打开弹层、切换年/月粒度均不提交日期，实际日期选择才调用原 onChange。

## 入口清单

| 模块 | 采用范围 | 保持的业务合同 |
| --- | --- | --- |
| 成本统计 | 五视图、窄屏下钻、人工分配状态、导出模式、日期粒度 | 五视图仅一个选中值；人工分配草稿、保存保护、分页、导出参数不变 |
| 银行明细 | 自动标签规则可用/停用视图、日期 | 切换状态只过滤显示，不停用规则 |
| OA 待付款核对 | 流程状态、关联支出流水候选状态、日期 | 状态/分页 query 及关联写入保持原 owner |
| 流水批次/批量账务/往来款/ETC | 原状态或家族筛选 | 数量、忙碌禁用、提交/撤回及冲突处理不变 |
| 关联台 | 异常状态/类型/金额分类、窄屏前后预览、发票录入方式 | 金额分类全局单选且允许无选择；预览确认和撤回链不变 |
| 设置 | 权限过滤后的主分类、项目状态、待找发票分组 | 隐藏选项不补造；原 panel 和设置草稿仍由页面持有 |
| 现金 | CashTabs 全部调用点、往来类别 | 现金 API 和状态仍在 cash 内；只共享无 I/O 的样式/组件 |
| 手工导入 | 动态流水/发票标签 | 原稳定 ID、编辑/概览、保存标记、附件、草稿与禁用状态 |
| 共享时间选择 | 年/月粒度与外层范围框 | 不新增日期模式；不改变查询值或年月网格的日历语义 |

待找发票、进项、销项的 `InvoiceCountSegments` 和反提 OA 状态控件共享同一高对比配色要求，保留现有结构；统计控件/计数合同不变。

表单 RadioGroup、现金收支类型字段、账户树、记录选择、多选筛选、保存/删除、排序、分页和展开收起不是本次视图分段控件，不转换。

## 旧代码清理

删除被替换的普通 button 分段结构、手写 tab/radio 状态、分隔条和无引用 import。删除旧成本独立按钮、现金下划线/类别卡片、设置选中覆盖、银行规则状态按钮、人工分配下划线、ETC 多处重复选中样式、手工录入旧选中样式、导出切换和预览旧 button CSS。原业务回调、权限校验、保存保护与 radio 焦点恢复仍有效，继续保留。

## 验收合同

- **UI-SEG-01**：跨视觉分组仅一个真实选中值；原无选中不被初始化成第一个；重复点击不增加请求。
- **UI-SEG-02**：点击、方向键焦点、空格/Enter 选择遵循原生控件；busy/权限禁用不触发业务回调。
- **UI-SEG-03**：动态标签切换保留各条记录的草稿、附件和保存标记，不以数组索引替代业务 ID；打开日期弹层及切换粒度不发查询。
- **UI-SEG-04**：桌面和窄屏保持连续外框、可见选中块、无独立阴影；控件内部滚动，不撑宽页面；reduced-motion 禁用位移动画。
- **UI-SEG-05**：原筛选、分页、详情、导出、保存、冲突、失败反馈及写后重读保持；三个发票统计页面回归不变。

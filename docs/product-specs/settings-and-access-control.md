# 设置页与访问控制

## 目标

设置页集中管理系统级配置，包括访问账户、只读导出权限、项目状态、银行账户映射、数据重置和 OA 同步相关操作。

## 访问控制

- 非授权用户不可见且 API 返回 `403`。
- 只读导出用户可以查看和导出，不能执行写操作。
- 全操作用户可以处理业务动作。
- 管理员可管理访问账户和执行数据重置。

## 数据重置

数据重置属于高风险操作，必须满足：

- 管理员权限。
- 明确影响范围。
- 当前 OA 密码或等价确认。
- 后台任务进度。
- 结果反馈和失败原因。
- 审计记录。

## 项目状态

项目状态用于成本统计范围和页面过滤。设置保存后必须影响相关 read model 和缓存。

## 验收标准

- 权限控制前后端一致。
- 只读用户不会看到误导性写入口。
- 数据重置离开页面后进度仍可恢复。
- 设置变更会清理或刷新受影响缓存。

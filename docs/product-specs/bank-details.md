# 银行明细

## 目标

银行明细页面用于查看所有导入流水，维护人工分类，展示自动分类和有效分类，并触发关联台、免 OA 批次、往来款等下游能力刷新。

## 分类口径

- 自动分类由系统识别，如手续费、工资、过节费、奖金、内部往来款等。
- 人工分类优先级高于自动分类。
- 有效分类是人工分类和自动分类合并后的业务事实。

## 联动

保存分类后必须触发：

- 银行明细自身刷新。
- 关联台相关月份 read model 失效。
- 搜索缓存清理。
- 免 OA 批次列表刷新。
- 往来款实时台账刷新。

## 验收标准

- 用户能看出自动分类、人工分类和有效分类的差异。
- 分类变更不会直接绕过后端事实模型。
- 已提交或已配对流水分类变化时，下游批次/关系进入需复核状态，而不是静默篡改历史。

# 银行明细

## 目标

银行明细页面用于查看所有导入流水，维护人工分类，展示自动分类和有效分类，并触发关联台、免 OA 批次、往来款等下游能力刷新。

## 分类口径

- 自动分类由系统识别，如手续费、工资、过节费、奖金、税款、代理国库税收收缴、社保款、内部往来款等。
- 人工分类优先级高于自动分类。
- 有效分类是人工分类和自动分类合并后的业务事实。

## 免 OA 自动分类规则

以下分类会进入免 OA 流水批量处理。自动判断必须保持收敛，不能用宽泛词造成误打标；未命中时应留给人工分类。

| 分类 | 自动判断逻辑 |
| --- | --- |
| 手续费 | 对方户名、摘要或备注包含“手续费”，或对方户名、摘要或备注包含“短信服务费”。普通“服务费”不自动归为手续费；用途和明细扩展字段只含“手续费”也不自动归为手续费。 |
| 工资 | 复用工作台特殊规则：流水必须是支出；摘要或备注包含“工资”；对方户名存在；对方户名不能识别为公司主体；金额可解析。 |
| 过节费 | 摘要、用途、备注或明细字段包含“过节费”。普通“慰问金”“节日慰问金”等不自动归为过节费。 |
| 奖金 | 摘要、用途、备注或明细字段包含：奖金、绩效奖、年终奖。 |
| 代理国库税收收缴 | 摘要、用途、备注或明细字段包含：代理国库税收收缴、国库税收收缴。单独“税收收缴”不自动归为代理国库税收收缴。 |
| 社保款 | 摘要、用途、备注或明细字段包含：社保款、社保费、社会保险费、缴纳社保。普通“社会保险”不自动归为社保款。 |
| 税款 | 摘要、用途、备注或明细字段包含：税款、缴纳税款、电子缴税、税库银、税务局、完税。普通“税费”和“扣税”不自动归为税款。 |
| 内部往来款 | 复用工作台特殊规则：收入和支出金额相同、对方户名识别为公司主体、不同公司账户、交易时间在 48 小时窗口内，且不存在多解或 active relation 占用。本方账户身份可来自账户名称、账号、导入银行和尾号或 `account_key`；内部往来款自动判定优先级高于所有文本标签。 |

## 联动

保存分类后必须触发：

- 银行明细自身刷新。
- 关联台相关月份 read model 失效。
- 搜索缓存清理。
- 免 OA 批次列表刷新。
- 往来款实时台账刷新。

## 验收标准

- 用户能看出自动分类、人工分类和有效分类的差异。
- 分类变更不会直接绕过后端事实模型。
- 已提交或已配对流水分类变化时，下游批次/关系进入需复核状态，而不是静默篡改历史。

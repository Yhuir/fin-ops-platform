# 产品规格索引

产品文档按业务域组织。这里沉淀当前有效口径，不收录历史 prompt，也不维护一次性执行计划。

## 核心链路

- `reconciliation-and-workbench.md`：银企核销、关联台、确认/撤回、异常处理和跨对象关系。
- `imports-and-etc.md`：导入、预览确认、文件生命周期、ETC 业务批次。
- `invoice-lifecycle.md`：发票生命周期、待找发票、OA 待付款核对、发票关系。

## 专题页面

- `bank-turnover-and-no-oa.md`：银行明细、流水标签、流水规则批量处理、往来款和 legacy 免 OA 流水批处理。
- `cost-tax.md`：成本统计、项目归因、税金抵扣、发票使用/收款。

## 平台能力

- `platform-settings-health.md`：设置、权限、数据重置、App Health 和后台任务可见性。

# 核心信念

## 业务事实优先

财务系统不能依赖备注、颜色、前端状态或临时筛选表达业务事实。凡是影响核销、台账、权限、导出、搜索、审计的状态，都必须有后端结构化模型。

## 预览先于写入

导入、数据重置、批量提交、自动匹配等高影响动作必须先让用户看到影响范围，再执行确认动作。

## 写模型和读模型分离

确认关联、撤回、异常处理等写操作只改变最小事实；页面加载、搜索、导出优先读取物化读模型。

## OA 是外部事实源，不是 app 内部状态

OA 数据通过适配层只读接入。app 可以建立映射、缓存和投影，但不能直接把 OA 原始库当作本系统主业务库。

## 可追溯比“看起来完成”更重要

每个财务闭环都要能回答：数据从哪里来、谁处理、为什么处理、处理了哪些对象、是否可撤回、撤回后如何恢复。

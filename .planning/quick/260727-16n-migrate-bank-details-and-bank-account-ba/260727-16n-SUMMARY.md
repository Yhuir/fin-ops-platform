# 结果

`/bank-details` 的账户余额、流水 rows、summary、分类 counts、筛选、分页和导出已切换到页面专属 canonical PostgreSQL query repository/service。读取在显式 `REPEATABLE READ / READ ONLY` snapshot 中完成；正式关系仅从 `app.workbench_pair_relations` 的 active 事实按当前可见或导出 row ids 有界查询。

前端和 API 已删除本页面 `read_model_status`、`source_versions`、refresh enqueue、202、轮询、operation barrier 和 fallback 语义。分类、普通标签和自动规则写入仍走原 canonical writer、审计与 CAS，成功后直接重新 GET。

# 复用与删除

- 复用现有账户 identity/余额聚合 SQL、bank detail row payload 和自动分类候选映射。
- 删除页面专属 read-model 读取、freshness/status 分支、refresh producer、前端 polling/status UI 和相关测试桩。
- 未修改共享 manifest、worker registry、scope policy、handler、deploy worker env 或共享 read model cleanup；仍有调用方的旧 reader/worker 留给主控统一清理。

# Quick Task 260621-n7i: 银行明细页面时间选择器简化为按年/按月和全部

## Scope

将银行明细页面右上角时间筛选从快捷按钮和自定义日期范围，改为：

- 一个时间选择器，支持按年选择和按具体月份选择。
- 一个“全部”按钮，用于清空日期范围。

## Plan

1. 更新 `BankDetailsPage` 的日期筛选状态和 UI，只保留 `all`、`year`、`month` 三种模式，并让请求参数按模式生成。
2. 更新银行明细页面 Vitest 和相关 Playwright e2e，覆盖年份、月份、全部和分页重置/导出筛选。
3. 更新 bank-details 模块文档和 GSD summary，记录设计决策、测试覆盖和未测风险。

## Acceptance

- 页面不再显示“本月 / 上月 / 近7天 / 近30天 / 今年”和任意起止日期输入。
- 默认仍是当前业务年 `2026-01-01` 到 `2026-12-31`。
- 选择年份请求对应整年；选择月份请求对应整月；点击“全部”不发送 `date_from` / `date_to`。
- 相关前端测试通过。

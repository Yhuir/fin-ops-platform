# Phase 37：App Shell 侧栏层级与 OA 身份区

## 目标

在不改变页面注册、路由、权限和业务 I/O 的前提下，降低侧栏拥挤感，增加固定 OA 用户区，并以静态品牌图标替换持续旋转的状态图标。

## 锁定决策

- 保持桌面展开/折叠宽度 `232px / 72px`，避免污染 Workbench 等依赖 `--sidebar-width` 的布局。
- 品牌区 `64px`；桌面导航行 `36px`，移动抽屉导航行 `44px`；菜单项间距 `4px`。
- 菜单字号 `14px/500`，激活态 `600`；分组标题 `12px/700`；图标 `16px`。
- 侧栏结构为固定品牌区、独立滚动导航、固定 `72px` 用户区。
- 用户区直接消费 `SessionContext`，主文案使用 `displayName`，次文案使用 `username`；弹层可显示部门，不发起额外请求。
- 使用本地首字头像，不加载 OA 远程头像；第一张 Figma 原图不可读，因此静态品牌 SVG 独立成可替换资源。
- 品牌图标仍是全局运行状态弹层入口，以静态状态点表达 ok/busy/error；删除旋转 SVG、keyframes 和旧 class。
- 不新增动画库或其它依赖；现有 HeroUI Popover 与 CSS transition 足够。

## 边界与非目标

- 不改 `pageRegistry`、页面名称、路由顺序和业务页面。
- 不新增登出、修改密码、账户管理或权限编辑。
- 不改 session API shape，不引入缓存、worker、read model 或后端逻辑。
- 所有新样式限定在 `.app-sidebar-*`。

## 验收

- 展开、折叠和移动抽屉均可访问，导航独立滚动，底部账号固定。
- 账号展示当前 OA 用户，弹层开关不产生业务 API 请求。
- 不存在无限动画；折叠完成不超过 300ms，浏览器帧间隔 p95 不高于 25ms，CLS 为 0。
- 旧旋转图标不可达，依赖清单和锁文件不变。

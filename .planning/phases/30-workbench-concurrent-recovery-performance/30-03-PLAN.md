<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| preview API → mapper | 服务端 DTO 仍需 schema/zone 校验，非法 selection 不能污染页面状态 |
| user click → network | 连续点击和多个入口必须由共享 pending 去重 |
| backend error → user copy | 内部异常、raw response 和 request metadata 不得被当作用户文案 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-30-03-01 | Tampering | preview DTO mapper | mitigate | selection 必须有合法 zone/status，非法 shape fail closed |
| T-30-03-02 | Denial of Service | duplicate preview clicks | mitigate | 同步 pending、防重入、所有 preview 入口共用状态 |
| T-30-03-03 | Information Disclosure | API error display | mitigate | code/status 白名单中文，unknown 不回显 raw message |
| T-30-03-04 | Elevation | disabled action rendering | mitigate | UI permission 只作辅助，后端权限仍为 authoritative |
| T-30-03-SC | Tampering | package supply chain | accept | 不安装新依赖 |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| client → preview API | row_ids、scope 和 expected version 均为不可信输入；必须有界、去重和 fail closed |
| preview API → active generation | 只读 derived snapshot，不得成为 formal write fact source |
| formal API → command/UoW | actor/tenant 来自服务端 auth，canonical facts/version/idempotency 在事务内重读 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-30-02-01 | Spoofing/Elevation | formal confirm/withdraw | mitigate | 保留服务端 OA auth context；客户端 actor/tenant 不可信 |
| T-30-02-02 | Tampering | preview/version | mitigate | row bound、expected generation/set 校验、missing/version drift fail closed |
| T-30-02-03 | Repudiation | formal UoW | mitigate | request ID、actor、relation history、audit 和 idempotency 不变 |
| T-30-02-04 | Information Disclosure | preview errors | mitigate | 稳定 code + 安全中文，由 request ID 定位内部日志 |
| T-30-02-05 | Denial of Service | preview selection read | mitigate | 有界 row_ids、set-based query、禁止完整 payload scan 和重复点击放大 |
| T-30-02-SC | Tampering | package supply chain | accept | 不安装新依赖或 package |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Browser state/form → API client | username、tier、expected_version 与用户操作均不可信；前端校验只用于 UX。 |
| Generic settings client → generic API | 旧 state/caller 可能意外夹带 ACL，必须在类型、serializer和后端双重阻断。 |
| Deterministic mocks → tests | mock 若比 production 宽松会制造安全假通过。 |
| Browser request context → backend | direct API 可绕过 UI，是真正 elevation regression 边界。 |

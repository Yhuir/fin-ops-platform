## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Read-only preflight evidence → production authorization | artifact/hash/fingerprint决定是否允许不可逆发布动作。 |
| Canonical deploy entrypoint → live API/DB/OA | quiesce、migration、candidate与smoke顺序决定漏洞窗口。 |
| Failed candidate → previous release/forward repair | 自动rollback可能重新激活vulnerable binary。 |
| Production sessions/tokens → post-deploy evidence | 多tier credentials与admin token必须secret-safe且不可混用为DB/OA凭据。 |

| T13-23 | HIGH | Elevation of Privilege | live cutover window | mitigate | API quiesce→0132/CHECK→ACL-safe candidate→smoke后才恢复服务。 |

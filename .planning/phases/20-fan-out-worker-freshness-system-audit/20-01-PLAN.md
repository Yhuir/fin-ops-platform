<objective>
把现有 `write_operation_e2e_smoke` 扩展为唯一可逆关系 closure runner：同一 scenario 内每个 confirm/withdraw checkpoint 都独立绑定 mutation、required fan-out、worker/durable queue、freshness、受影响页面 API 和新的只读 System Audit。用 bank+invoice、bank+turnover、bank+OA+invoice 三种关系形状证明正反向闭环；不新增第二套 relation/queue/freshness/Audit owner，不做 17×operation，并删除迁移后无 caller 的旧一次性 execution branch和伪闭环逻辑。
</objective>

<grill_gate>

- Canonical write 只能走 Workbench action API → `WorkbenchRelationCommandService` → `WorkbenchWriteUnitOfWork`；测试不得直接写 relation/read-model/outbox/dirty/readiness。
- Runner 复用 `write_operation_slo_audit`、`http_slo_probe`、operation impact matrix和System Audit HTTP owner；禁止复制SQL、worker、freshness或Audit算法。
- 每个 checkpoint在自己的数据库 started_at之后证明全部 required expectations；confirm与withdraw不得共享最终一次SLO/Audit。
- 每个 checkpoint 的正式写请求必须携带本场景唯一 `idempotency_key`。HTTP 成功后，通过 `write_operation_slo_audit` 内唯一只读 PostgreSQL evidence owner 从 `app.workbench_idempotency_records` 的 committed record 精确解析非空 `outbox_event_ids`；不把内部 event ID 暴露到业务 HTTP DTO。SLO 查询只能接受这些精确事件 ID；`started_at + profile` 仅用于时间窗/防御性过滤，不能作为归属证明。报告列出逐 expectation 命中的 event ID/scope。缺 required expectation、event ID 不属于本 checkpoint、或 scope 不在正式 required/optional impact contract 中才 fail closed；属于同一精确 ID 集且被合同允许的 optional scope只记录、不失败。
- System Audit必须解析并校验同一新报告的system audit id、snapshot、contract、17/16 page counts、integrity/freshness/queue；external unknown保持允许且不扩大声明。
- 每个 affected consumer 必须同时通过 freshness gate 和最小 typed business assertion；断言只支持明确的 JSON Pointer `equals`/`contains` 合同，并由 scenario 对经过过滤的确定性 API payload 指定，不引入第二套页面业务算法。
- 新可逆scenario必须声明test-owned fixture、shape、cleanup=withdraw和approval；不得由discovery自动选择普通业务对象执行confirm。
- confirm 已提交而其后 closure gate 失败时，原失败结论保持不变，但 runner 必须进入 recovery cleanup：使用正式 preview + expected_versions 的 withdraw checkpoint 清理 test-owned relation；清理失败输出不含敏感数据的 recovery-required artifact。网络结果不明确时禁止盲重试，只有读回 canonical postcondition 证明 relation active 后才允许清理。
- 保留的legacy scenario输入只映射为一个checkpoint并走同一执行函数；迁移后不存在第二条运行分支。
- 真实PostgreSQL测试只允许显式disposable test DB；缺外部环境结构化skip/input-required，不得连接生产或伪造通过。

</grill_gate>

<objective>
把银行流水导入页从 unavailable 升为可证明的 direct-canonical workflow 页面：在单一 repeatable-read read-only snapshot 内，证明 import file/session、file object hash registration、preview batch/row audit、confirm 后 canonical bank transaction ownership/identity、import job 与 durable queue 的完整闭包；下游 read models 只作为写后影响目标，不冒充页面消费者；迁移并删除仍可绕过 file/session gateway 的旧 JSON HTTP import 路径。
</objective>

<grill_gate>

- 页面没有 own manifest read model，也不展示 pairing relation；registry 必须使用 `read_model_keys=()`、`relation_proof_required=false`。`bank_detail`、`bank_account_balance`、Workbench、cost、search 等是 confirm 后 operation targets，不是页面 consumer。
- 页面 server data 来自正式 `/imports/files/*` session：`app.import_files` + `app.file_objects`、`app.import_batches`、`app.import_batch_rows`、`app.bank_transactions`、`job.import_jobs` 与 durable outbox/dirty scope。浏览器选中的本地 File/checkbox 是用户输入状态，不是 App canonical fact；一旦 preview 返回，全部 server preview rows/counts/decisions 必须由已登记 session/batch/row facts重算。
- expected-set 不能把 batch/raw payload 与自己比较后通过。必须分别从 structured file/batch/row columns、normalized payload、canonical bank transaction identity/source ownership 和 job/result references 做交叉 equality；created/status-updated/duplicate/error/suspected decisions 各自有明确引用合同。
- `app.file_objects.content_sha256/size/object_key/storage_uri` 只能证明 App 接收并登记的文件对象；Audit 不读取对象字节、不调用 S3/MinIO、不把 hash registration 冒充银行外部 control total。银行文件是否漏页/漏行/被篡改必须由 external evidence gate 单列。
- `file_import.confirm` job 通过 session/file/batch type 归属到银行导入。pending/processing/retryable failure 或相关 current-effective outbox/dirty scope 阻断 freshness/queue；terminal failure、orphan job/result/batch/member 阻断 integrity。Audit 不 retry/ack/delete/enqueue。
- 旧 `/imports/preview`、`/imports/confirm` HTTP 入口仍能写相同 canonical facts，是潜在平行链。必须做 whole-repo caller + docs/ops scan；若无正式外部生产 caller，迁移测试/内部调用并删除 route/handler/client。若存在有 owner 的正式调用，必须先收口到同一 file/session application gateway，禁止保留第二套 normalization/confirm/job contract。
- `FileImportService.snapshot/from_snapshot` 是 file/session 跨进程恢复端口，不是 full-state fallback；只有证明已无正式 owner 才删除，不能为满足“旧代码删除”误伤 worker recoverability。
</grill_gate>

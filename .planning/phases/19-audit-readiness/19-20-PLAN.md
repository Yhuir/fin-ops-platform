<objective>
建立银行、OA、普通发票、ETC 四类外部 control evidence 的唯一版本化边界，使 App Health System Audit 能在同一 PostgreSQL read-only snapshot 内，把独立 external complete-snapshot manifest 与 App canonical facts 做精确 expected-set、关键字段 fingerprint 和控制总额双向 equality。没有可信 manifest、manifest 已撤销/过期/覆盖不全，或存在缺失/多余/字段漂移时必须 fail closed；内部绿色不得继续冒充外部来源完整。
</objective>

<grill_gate>

- control total、row count、file hash 或“同步成功”单独都不能证明完整性；v1 manifest 必须包含 exact item set。相同 count/amount 下替换一条记录的反例必须被 item equality 阻断。
- v1 只支持 `coverage_mode=complete_snapshot`、`scope_key=all`。不实现 partial/month coverage 的复杂合并，因为缺少完整 coverage ledger 时会产生绿色遗漏；未来扩展必须另立合同。
- 外部 evidence 是独立输入，不得由 App 当前 canonical rows 反向生成后自证。manifest 需要 source system、source snapshot id、observed_at、original artifact sha256/size、collector contract/version、item keys/critical fields/fingerprints 和 declared controls；CLI 可以校验但不能声称替代来源系统真实性。
- 四类 canonical comparer 必须有明确、稳定、文档化的 normalized identity/field contract：bank transaction、OA application/item、ordinary invoice、ETC invoice/archive evidence。普通 invoice manifest 不重复承接 OA attachment/ETC invoice 的来源责任；所有 App canonical source classes 必须恰好由一个 external domain owner覆盖。
- evidence header/items 必须 immutable append；撤销是显式、可审计状态变化，最新 evidence 被撤销后不得静默回退旧版本变绿。重复登记同 fingerprint幂等；不同内容创建新版本。
- 登记/撤销只走 domain service + repository + 显式运维 CLI，要求 `--apply --reason --actor`，写 `audit.events` 并支持 dry-run/structured JSON。不得新增 HTTP/UI 写入口，不得把 manifest item原文或敏感字段写入日志。
- System Audit 仍只读：不能采集外部系统、不能登记 evidence、不能 enqueue/refresh/repair。它只读取 caller-owned snapshot 内已登记 evidence，并输出 external status、evidence id/version/as-of/fingerprint、page coverage和 bounded claim。
- external `pass` 的强声明只能是 `proven_as_of_external_evidence`，绑定 external observed_at、source snapshot和当前 immutable App system snapshot；不得承诺 Audit 后写入或外部实时状态。
- `PageAuditRegistration.external_source_boundary` 继续作为说明文字，但不得再决定 status。新增显式 external evidence dependency keys；旧 `_external_evidence(registrations)` free-text classifier 必须删除，不能保留 parallel fallback。
- 必须用 disposable PostgreSQL 全迁移验证 clean pass和破坏性反例；不得连接生产、登记生产 evidence、部署、refresh、repair或写生产数据。
</grill_gate>

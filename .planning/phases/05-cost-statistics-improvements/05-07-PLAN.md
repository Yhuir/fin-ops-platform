# 05-07 Bounded Execution Prompt：成本页轻量 freshness 锁定遮罩

## 本轮唯一目标

只在 `/cost-statistics` 页面实现 Impeccable `Ledger Calm` 轻量交互锁：当首屏加载、生命周期重校验、API/App Status 表明 `refreshing|stale|missing|failed|unavailable|schema_mismatch|source_mismatch`，或成本标签规则正在等待 operation barrier 时，锁定成本业务操作，显示约 80% 透明的页面内遮罩和顶部内联状态轨；确认 fresh 后自动解除。

本轮不修改后端 API、read model、worker、Audit、共享 App Shell、共享 StatePanel 或其他页面。保持 `DEPLOYMENT_HOLD`，不进入生产或部署验证。

## Effective state 合同

页面只派生一个 `effectiveCostPageState`，不引入新的外部 store。优先级固定为：

1. `error|unavailable`：首屏/重校验请求失败，或 API/App Status 为 failed/unavailable/missing；
2. `stale`：API/App Status 为 stale/schema/source mismatch；
3. `refreshing`：API/App Status 为 loading/pending/processing/refreshing，或标签规则保存/operation barrier 未完成；
4. `loading`：没有可确认 fresh 的当前 request payload；
5. `fresh`：当前 request identity 的 explorer payload 明确 fresh，且精确 App Status scope 没有 non-fresh 反证。

只有 `fresh` 解锁。合法 `row_count=0` 仍是 fresh empty，不得被误判成 loading。

App Status 只匹配 `readModelKey=cost_statistics` 且 `scopeKey=currentCostStatisticsScopeKey` 的精确 scope；其他月份 busy 不得锁当前页面。App Status 缺少该 scope 时不凭空判 stale，仍由 explorer gate 决定。精确 scope 状态变化后只触发当前 explorer 重校验，不新增 cost-specific polling/SSE。

## DOM、视觉与交互合同

- 页面标题与 `PageBusinessAuditIcon` 留在锁定边界外；App Shell、导航与全局 App Status 始终可用。
- 视图 tab、范围、刷新、标签规则、导出、表格和 load-more 使用原生 `inert` 与 `aria-busy`；不得只靠 `disabled` 或透明层。
- 内容区外层相对定位；锁定时内容 opacity 为 `0.62`，覆盖一层 `color-mix(in srgb, var(--fp-page) 20%, transparent)`。遮罩 `pointer-events:auto`、`touch-action:none`、`user-select:none`，无 blur/shadow/radius/card。
- 状态轨在页面流顶部，最小高 `44px`，只有细分隔线、14px 状态标记、主/辅文案和必要的 `重新检查` ghost button；`role=status`、`aria-live=polite`、`aria-atomic=true`。
- initial：`正在加载成本统计`；refreshing：`成本数据正在同步`；stale：`正在更新至最新数据`；unavailable：`成本数据暂未就绪`；request error：`无法确认成本数据状态`。
- `prefers-reduced-motion: reduce` 时状态标记静止；其他状态动效只允许 opacity/transform，120–180ms，不动画布局。
- locked 且没有 fresh rows 时可显示低成本页面骨架轮廓，但不得渲染真实 empty 文案或旧业务值。

## 焦点、portal 与生命周期合同

- 锁定前若焦点位于成本业务控件或成本页自有 portal，记录该元素并把焦点移至可编程聚焦的状态轨；不抢 App Shell/Audit 焦点。
- 解锁后仅当原元素仍 connected、可用且不再 inert 时恢复；否则回到 `tabIndex=-1` 的成本统计标题。没有发生焦点迁移时不得主动抢焦点。
- 进入锁定立即关闭并清除 transaction detail 与 export center，关闭范围 popover，并 abort detail/export-reference 的可取消请求，防止晚到响应重新打开旧 portal。
- 标签规则 drawer 保存中沿用现有 saving/barrier；其他 non-fresh 状态保留草稿和 drawer 壳，但其 body/footer inert，close affordance 可用。
- `visibilitychange` 从 hidden 回 visible、已失焦窗口重新 focus、`pageshow.persisted=true` 都先清除当前可操作 explorer，再发一次 gate 请求。对同一返回事件去重，避免 focus/visibility 连续触发两次。

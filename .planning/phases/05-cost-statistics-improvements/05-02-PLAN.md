<implementation_contract>

1. handler 从 `event.source_version` 或 payload 读取版本，保留合法 `0`，缺失、布尔值、负数或非整数 fail fast。
2. month/parent builder 显式接收 `source_version`；worker 不兼容无版本 builder。
3. cost repository 新增窄的 conditional publish 方法；它在单个 transaction 中：
   - 复用现有 partial unique index，按 tenant/scope 锁定唯一 `pending` / `processing` active dirty row，不扫描排序历史 terminal rows；
   - 只有 active dirty 版本与 event version 精确相等时才写 parent/rows/obsolete deletes；
   - 不匹配或缺失时返回 false，零写入。
4. parent obsolete month scopes 只作为同一 conditional publish 的 `changed_scope_keys` 被删除。
5. repository 拒绝 publish 时禁止写 Redis、禁止 enqueue parent、禁止 complete dirty，并返回稳定 stale result。
6. publish 成功或依赖版本确实 unchanged 时，handler 使用 `complete_read_model_refresh(..., source_version=event_version)`；返回 false 时保留新 dirty，并返回 refreshing/stale-after-rebuild 结果。
7. Redis 仍只在 conditional publish 成功后写；本轮不增加缓存层。

</implementation_contract>

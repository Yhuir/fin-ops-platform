# 05-05 Bounded Execution Prompt：首屏 I/O 隔离与前端旧缓存删除

## 本轮唯一目标

在不改变成本统计 HTTP DTO、后端 read model、其他页面或共享 UI 的前提下，删除当前页面首屏最大的已量测 I/O 放大器：

1. 删除 `api.ts` 的 5 分钟 `costExplorerCache` 及其 get/clear API；
2. 删除成本页 mount 时无条件请求 `active:all` 的 export reference effect；
3. 首屏只请求当前可见 scope，不为未打开的导出中心或其他视图预取数据；
4. 只有项目/费用类型导出确实需要全期间选项且当前尚无 `all` payload 时，才按需请求一次 `active:all`；失败时保持导出中心关闭并显示明确错误；
5. scope/view/domain refresh 切换时清空上一 scope 的 explorer 数据并进入真实 loading，禁止把旧 scope 暂时显示为新 scope；
6. 删除 whole-repo 已证明无生产调用方的前端 `fetchCostStatisticsMonth`、`fetchProjectCostStatistics` 及仅为它们存在的 API types；
7. 保留 AbortController/latest-effect ownership，不新增前端 TTL、singleflight、全局 store、SSE、cursor 或 fallback。

本轮不实现 view-specific cursor API、后端索引、请求期 expected-source provider 删除、Impeccable 遮罩、Audit、streaming export 或后端旧 module/route 删除。上述事项必须由本轮完成状态决定下一 prompt，禁止在本文件预生成。

## 实现合同

### 当前 scope explorer

- `explorerData` 初始为 `null`；每次 effect generation 开始立即清空旧 payload、置 loading，并由自己的 AbortController 独占结果写入。
- effect cleanup 后的旧响应不得写 state；加载失败不得保留上一 scope 的旧内容。
- domain/manual/tag-rule refresh 不再清 JS cache；只增加 refresh nonce 或直接重新取当前 scope。
- 当前 `explorerMonth === "all"` 成功时可复用该同一 fresh payload 作为导出参考，不发第二个请求。

### 导出按需读取

- time/bank-tag 导出打开不需要项目/费用选项，不请求 `active:all`。
- project 导出通常已在 project view 的 `all` explorer 上；直接复用。
- expense-type 导出若当前 explorer 不是 `all` 且没有 fresh reference，点击导出中心时才请求 `active:all`，成功后再打开；加载期间防止重复点击。
- 按需请求失败时导出中心不打开，页面展示可重试的明确错误；不得吞错或回退旧 cache。
- `exportReferenceData` 只允许来自本次 mount 生命周期中成功返回的 fresh API payload，不从 module-level cache 初始化。

### 旧 client 删除

- whole-repo literal scan 已证明 `fetchCostStatisticsMonth` / `fetchProjectCostStatistics` 除声明外无调用；删除其实现和仅由它们使用的 API/types。
- 删除 cache tests，替换为“fetch 每次触发真实请求且不保留 module cache”的 API contract，或通过页面 request-count 测试证明首屏无 `month=all`。

## 验收标准

1. 初始 time/month 页面只出现 `month=2026-03&project_scope=active` explorer 请求，不出现 `month=all`。
2. 切换具体月份时旧月份行立即退出可操作内容，旧响应不能覆盖新 scope。
3. time/bank-tag 打开导出中心不触发 `month=all`；project 复用其已加载的 all payload；expense-type 只有首次打开且确需选项时才请求 all。
4. API client 无 module-level explorer cache、TTL、get/clear export；页面卸载再挂载必须重新经过后端 freshness gate。
5. 两个无调用旧 API client 和关联 type 删除，whole-repo current-code scan 为零。
6. 五视图、详情、标签规则保存后刷新、导出 preview/download、non-fresh/error/empty 行为回归通过。
7. 文档明确本轮关闭首屏 all-prefetch/cache，但 cursor/active:all payload 大小仍未闭环，不得声称最终 SLO 已达成。

# 05-15 Bounded Execution Prompt：成本导出有界查询与 write-only XLSX

## 本轮唯一目标

删除成本统计 bulk export / export-preview 对 `get_cost_statistics_view(...)` 完整 payload、`time_rows` 和
`bank_flow_time_rows` 的全量装载依赖，改为成本模块自有的一条筛选汇总 + 有界分页 repository I/O。preview 最多读取 8 行；
bulk XLSX 在判定 20,000 行上限后按固定批次读取并直接追加到 openpyxl write-only worksheet，不能构造完整 entries/rows list。
导出完成后重新校验同一 read-model 发布版本，版本变化时丢弃结果并返回既有 non-fresh 409。保持 HTTP 文件响应、筛选、文件名、
sheet shape、错误 DTO 和 `DEPLOYMENT_HOLD` 不变。

## 必须满足的生产合同

1. preview 只能从 SQL summary + 最多 8 行构造；`summary.row_count/transaction_count/total_amount` 仍代表完整筛选集合。
2. bulk export 先读取 summary 并执行 row-limit；超限时不得创建 workbook或继续取批次。
3. 每次 repository row payload 最多 1000（preview 为 8）；不能返回完整 payload或完整命中行 list。
4. time/bank_tag 使用 bank-flow rows；project/expense/month 使用 OA cost rows；selected tag contract继续来自 freshness gate。
5. month summary、project month/year aggregate、project detail、expense_type、time、bank_tag 的既有列、sheet顺序、文件名和筛选语义不变。
6. bulk workbook 使用 `Workbook(write_only=True)`；直接 append批次，禁止完整 entries/rows list。最终 bytes仍保持既有 route合同。
7. 初始和结束 gate 的 schema/source_versions/published_source_version必须一致；不一致时丢弃 bytes并抛既有 `CostStatisticsReadModelNotFreshError`。
8. repository unavailable/non-fresh 时 fail-closed，不回退 full view、Redis或 live scan。
9. explorer page、detail point lookup、month API、route、permission 与其他页面 read model不变。
10. production/tests 中 bulk preview/export 对 `_filtered_entries_from_read_model` 和 full payload的 caller归零；不保留 fallback或兼容 alias。

## 七类测试责任

1. Business core unit：适用；筛选、范围交换、聚合、方向汇总和 row-limit边界。
2. Service-layer：适用；cost repository export summary/page、bounded batches、version recheck与无 full payload I/O。
3. API contract：适用；既有 preview/download shape、sheet/filename、400 limit与409 non-fresh不变。
4. Read model/cache/background job：适用；fresh gate前后版本一致、non-fresh零 rows、Redis/full payload不参与导出。
5. Frontend interaction：行为未改；复跑既有 cost API/Browser contract相关单元回归，不新增UI。
6. End-to-end integration：适用；本地 read model publish fixture -> preview/export -> workbook解析；真实PostgreSQL/worker留到统一部署后。
7. Existing regression：适用；成本 explorer/page/detail、manifest、repository boundaries和其他页面 port隔离。
